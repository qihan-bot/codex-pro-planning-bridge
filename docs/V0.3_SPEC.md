# Codex Pro Planning Bridge v0.3 Specification

## Version Goal

v0.3 upgrades the project from a planning assistant into a continuous planning loop system.

The goal is:

```
Collect Context
      |
      v
ChatGPT Pro Planning
      |
      v
Plan Validation
      |
      v
Codex Implementation
      |
      v
Drift Detection
      |
      v
Memory Update
```

## Core Objectives

1. Introduce a persistent project understanding layer.
2. Detect differences between planned and actual implementation.
3. Provide structured feedback loops before major changes continue.
4. Prepare the foundation for v1.0 AI Software Architect capabilities.

---

# 1. Project Memory System

## Purpose

Store long-term project decisions and constraints.

Directory:

```
.codex/project-memory/

architecture.md
decisions.md
constraints.md
known-issues.md
```

## Memory Types

### Architecture Memory

Stores:

- system architecture
- technology choices
- module relationships

### Decision Records

Format:

```markdown
# Decision

Date:

Decision:

Reason:

Alternatives rejected:
```

### Constraints

Stores:

- compatibility requirements
- deployment restrictions
- security requirements

---

# 2. Plan Diff Engine

## Purpose

Compare original planning documents with current repository state.

Input:

```
PLAN.md
repository snapshot
implementation status
```

Output:

```
PLAN_DIFF.md
```

## Detection

Detect:

- completed tasks
- missing tasks
- changed architecture decisions
- unexpected files
- implementation drift

Example:

```markdown
# Implementation Drift

Completed:
- Database migration

Missing:
- API compatibility layer

Changed:
Redis cache replaced with local cache
```

# 3. Planning Loop Engine

New core component:

```
src/codex_pro_planning_bridge/loop.py
```

Responsibilities:

- coordinate planning workflow
- manage states
- trigger validation
- trigger memory updates

Workflow states:

```
NEW_TASK

CONTEXT_READY

PLAN_READY

VALIDATING

IMPLEMENTING

REVIEWING

COMPLETED
```

---

# 7. Non Goals

v0.3 does not include:

- OpenAI API calls
- automatic ChatGPT webpage scraping
- autonomous browser control
- automatic code modification without Codex approval

The design principle remains:

ChatGPT Pro = Architect

Codex = Engineer

---

# 8. Acceptance Criteria

v0.3 is complete when:

1. A project can maintain persistent architectural memory.
2. A PLAN.md can be compared against repository changes.
3. CLI provides one unified workflow.
4. Tests cover core planning components.
5. The full planning loop can be demonstrated on a real repository.
