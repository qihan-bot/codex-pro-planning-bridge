# Codex Pro Planning Bridge v0.3.1 Specification

## Version Goal

v0.3.1 adds safety, recoverability, and audit capabilities on top of the v0.3 planning loop.

The goal is to make planning workflows durable and reviewable:

```
Task
 |
 v
Context Collection
 |
 v
ChatGPT Pro Planning
 |
 v
Plan Approval
 |
 v
Validation
 |
 v
Implementation
 |
 v
Review
 |
 v
Memory Update
```
Design principles remain:

```
ChatGPT Pro = Architect
Codex = Engineer
Human = Final Approver
Repository = Source of Truth
```

---

# 1. Workflow Event Log

## Purpose

Add an append-only audit trail for workflow execution.

Storage:

```
.codex/workflow/

state.json
history.json
 events.jsonl
```

## Event Format

Example:

```json
{
  "timestamp": "2026-08-20T12:00:00Z",
  "event": "PLAN_VALIDATED",
  "from": "VALIDATING",
  "to": "IMPLEMENTING",
  "actor": "codex"
}
```

Requirements:

- append-only
- human readable
- Git friendly
- supports workflow debugging

---

# 2. Plan Approval Protocol

## Purpose

Prevent implementation before human approval.

Workflow:

```
ChatGPT Pro
    |
    v
PLAN.md
    |
    v
Human Review
    |
    v
PLAN_APPROVED
    |
    v
Implementation
```

Storage:

```
.codex/pro-plan/

PLAN.md
APPROVAL.json
```

Approval metadata:

```json
{
  "approved": true,
  "approved_by": "user",
  "timestamp": "2026-08-20T12:00:00Z"
}
```

Unapproved plans must not transition to IMPLEMENTING.

---

# 3. Workflow Recovery Commands

Add CLI commands:

```bash
cpb status
cpb resume
cpb pause
cpb cancel
cpb history
```

Capabilities:

- inspect current state
- resume interrupted workflows
- pause waiting workflows
- cancel invalid workflows
- inspect execution history

# 4. Symbol Graph Foundation

## Purpose

Extend repository intelligence from symbol indexing to relationship analysis.

New component:

```
src/codex_pro_planning_bridge/intelligence/

symbol_graph.py
```

Model:

```
File
 |
 +-- Class
      |
      +-- Function
           |
           +-- Dependency
```

Initial capabilities:

- function relationships
- class ownership
- import dependencies
- call relationships

No external AI API required.

---

# 5. Workflow Architecture Changes

Recommended structure:

```
src/codex_pro_planning_bridge/workflow/

engine.py
transitions.py
handlers.py
recovery.py
```

Responsibilities:

## engine.py

- run workflow
- resume workflow
- pause workflow

## transitions.py

- validate state changes
- enforce allowed transitions

## handlers.py

- execute workflow actions

## recovery.py

- restore interrupted sessions

---

# 8. Non Goals

v0.3.1 does not include:

- OpenAI API calls
- automatic ChatGPT scraping
- browser automation
- autonomous source modification
- bypassing user approval

---

# 9. Acceptance Criteria

v0.3.1 is complete when:

1. Every workflow transition is recorded.
2. Interrupted workflows can resume.
3. Implementation requires explicit plan approval.
4. Symbol relationships can be queried locally.
5. Workflow history can be audited.
